# Post-AGI Community

## Features

### Dark/Light Mode Toggle

- Use CSS variables and JavaScript to switch themes.
- Save preference to localStorage.

### Keyboard Navigation

- Ensure all buttons/links are focusable (tabindex).
- Add :focus-visible styles for clarity.

### SEO & Performance

- Add meta tags (description, og:image).
- Compress images (if added later) and minify CSS/JS.
